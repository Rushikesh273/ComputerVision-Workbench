# Computer Vision with YOLO and OCR

## Project Objective
This project explores the fundamentals of **Computer Vision** through practical implementations of YOLO (You Only Look Once) and Optical Character Recognition (OCR). The objective is to understand how object detection and text recognition work by building and experimenting with real-world applications.

## Setup Instructions
1. Clone the repository:

cd <repository-folder>

2. Install project dependencies:
bash:
pip install -r requirements.txt
